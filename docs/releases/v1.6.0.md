Airdrop 1.6.0 removes the Tailscale requirement and guides connection setup entirely inside the app.

- Choose direct Wi-Fi or optional free internet sharing without buying a server/domain or entering credentials. The internet option uses Cloudflare Quick Tunnels and downloads its checksum-verified component inside Airdrop on first use.
- After the connection is verified, choose whether sharing should continue when the window closes. This choice is saved and can be changed anytime in Settings. With background sharing off, opening the app reconnects using the saved mode.
- Pair an iPhone or Android using the in-app QR code. The mobile web app shows connection status and supports file upload/download in Safari/Chrome without a VPN app.
- Fix authenticated mobile downloads by using short-lived, single-use download tickets while preserving strict origin validation.
- Preserve existing shared files, clipboard data and settings. Old Tailscale connection preferences migrate to the new setup wizard; the application no longer starts the old helper or installs Tailscale.

Wi-Fi sharing uses HTTP and requires a trusted, reachable local network. Free internet sharing passes through Cloudflare, which terminates TLS; its temporary account-free service has no uptime guarantee. A new app/tunnel session uses a fresh pairing link. Mobile browsers may pause when backgrounded, so keep transfers open until they finish. Native iOS/Android background services are not included.

Script installations can use Settings → Check for updates → Update. Native DEB/RPM assets and the standalone installer are available below. AppImages contain the desktop companion and require an existing local backend. Signed package repositories and Flatpak updates use their separate protected publication channels.

Validation includes unit/integration tests, x64 and ARM64 native builds, installed Electron tests, wizard/background-permission tests and iPhone/Android browser emulation. Physical iOS/Android hardware and native Safari acceptance are separate from browser emulation.
