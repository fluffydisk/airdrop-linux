Airdrop 1.6.6 adds automatic sharing-address DNS recovery and makes background sharing the default.

- If ordinary desktop DNS cannot resolve the account-free sharing hostname, Airdrop tries DNS over HTTPS for that hostname only, then verifies the real HTTPS endpoint using the original hostname, SNI and certificate validation. The system DNS configuration is unchanged. Resolver queries contain no pairing token or access key.
- HTTPS verification runs in the bundled standalone Node runtime, with the original hostname and certificate validation. A parent-enforced deadline kills a stalled worker; the desktop remains responsive even if TLS work blocks. Private pairing credentials are sent only over the worker IPC channel.
- DNS answers that are not available yet are retried after five seconds, so temporary registration delays cannot occupy the whole connection retry window.
- The fallback applies only to public Cloudflare Quick Tunnel hostnames after a DNS error. Configured proxy routes, private relay domains, HTTP access denials and certificate failures do not select a direct fallback connection. Connection details identify the verification transport.
- Background sharing starts enabled for new and previously undecided installations. Flatpak still requires OS permission; denied permission stays off and is explained in the app. Previously explicit off choices are preserved. Settings and the setup wizard can change the preference, and Quit stops sharing.
- With permission granted, closing the window keeps a pending phone verification and its sharing link alive. Phone verification remains available when desktop DNS recovery cannot be used, and its QR panel scrolls into view.
- Same-Wi-Fi discovery accepts non-public carrier-grade NAT addresses on physical/network interfaces while excluding the host Tailscale interface. Globally routable IPv4 and IPv6-only LAN sharing remain outside this local HTTP mode.

Account-free internet sharing still uses Cloudflare's temporary service and its availability limits. Tailscale remains an optional embedded provider. Mobile browsers may suspend background transfers; physical Safari/iOS/Android acceptance is not implied by browser-emulation tests.

After signed Flatpak publication, use Settings → Check for updates → Update → Quit to finish update, then reopen Airdrop.
