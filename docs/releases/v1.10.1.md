# Airdrop 1.10.1

Quick Share is available directly in **Nearby Share** in the standard standalone
installer, AppImage, DEB, and RPM builds. Open **Receive** to make the application
discoverable or choose **Send** and select the files to discover recipients.
Verify the displayed code and accept the transfer on the receiving device.

When receiving, the app tries the Bluetooth Classic RFCOMM path used in the
Samsung phone tests. It falls back to BLE and LAN when Classic cannot register.
The RFCOMM path uses the same encrypted handshake, explicit consent and received
files directory as the existing helper. Leaving Nearby Share releases the
receiver and discovery resources. Compatibility varies by Bluetooth adapter and
phone. A failed connection or unconfirmed delivery remains visible as such.

The Classic inquiry diagnostic that temporarily changes system Bluetooth
discoverability stays in the lab. This release also leaves the signed Flatpak and
Snap permissions unchanged. Their builds do not ship native Bluetooth Quick Share.
Apple AirDrop is unavailable.
