## Click to select, double-click to open

- Click a file or folder once to select it. Double-click a folder to enter it inside Airdrop.
- Double-click a desktop file to open it in the computer's default application. Enter opens the focused item too.
- Keep file cards in place when selection changes so double-clicks work reliably, including on filenames and icons.
- Keep checkboxes dedicated to selection. Files in Trash must be restored before opening.
- In the web/PWA interface, double-clicking a file starts its download so it can be opened on that device.
- Validate shared-root boundaries and reject symbolic links, special files and invalid paths before handing a desktop file to its default application. Show application-opening failures in the file manager.

## Updating

Existing installed v1.4.0 users can use **Settings → Check for updates → Update**. The installed updater replaces the desktop, server and web UI together, preserving files, settings and credentials. AppImage users use the matching replacement AppImage download; backend updates remain separate.

For a fresh full installation, download `install-prebuilt.sh` and run it as your normal user. Linux x64 and arm64 install bundles and AppImages are included. `SHA256SUMS` and `airdrop-update.json` cover the release assets.

## Validation

47 automated tests, plus real Electron and Chromium interaction tests covering selection, double-clicks, keyboard opening, download behavior, default-application dispatch, failure messages and unsafe-path rejection. Both release architectures run the automated suite before packaging.
