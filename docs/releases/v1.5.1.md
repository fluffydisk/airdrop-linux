# Airdrop Linux 1.5.1

This release brings the recent desktop improvements to normal installer and
native package users, including updates from 1.5.0 through Settings.

- Keep the welcome screen usable while Tailscale connects; show certificate and authentication progress.
- Manage device sharing and its verified address/QR in Settings.
- Select all files or trash items; confirm permanent trash deletion.
- Move files between Airdrop folders by dragging; dropping in the same folder makes no duplicate. Existing destination files are never overwritten.
- Hold Alt while dragging to copy files to another application.
- Keep folder integration, file sorting, upload/download, ZIP and clipboard sharing.

Normal installer updates preserve shared files, configuration and desktop state.
Script installations use Settings > Check for updates > Update. Package-managed
installations use their package manager. Flatpak has its separate signed channel.
Native installations still need their existing service/runtime prerequisites;
this release does not claim an authenticated physical-device Tailscale test.

Existing v1.5.0 tags and assets remain unchanged. Checksums and airdrop-update.json
are generated from the actual release packages for both x86_64 and ARM64.
