# Airdrop 1.7.0

A clearer Linux desktop for sharing files, clipboard text, and connecting your devices.

- Redesigned light and dark themes with readable controls, consistent spacing, visible keyboard focus, and navigation labels retained at smaller window sizes.
- Transfer opens on your workspace sharing action. Temporary guest sharing remains available in “Share with a guest”.
- Settings → Updates shows your installed version, distribution, last check, release notes, progress, and appropriate update actions.
- Automatic stable-release checks can be disabled. Checks defer while a desktop transfer is running; installation always requires an explicit action.
- Standalone installations retain verified downloads, transfer draining, backups and rollback. Interrupted updates offer recovery.
- Flatpak retains its signed-origin update portal. Success is reported only after the portal helper exits successfully.
- DEB/APT, RPM, Snap and AUR installations discover releases and provide their package-manager instructions. Repository or store availability may lag the GitHub release. Airdrop does not run privileged package commands.
- AppImage opens the matching download; replace the AppImage after checking its checksum. It does not claim to install the download or update the separate local server.

Existing files, clipboard, pairing information and preferences are preserved. The mobile web interface is unchanged.
