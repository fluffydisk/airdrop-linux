# Airdrop 1.10.2

The signed upstream Flatpak now includes the Quick Share helper for x86_64.
**Nearby Share → Receive / Send** uses the same helper as the native desktop
packages, including Bluetooth Classic RFCOMM receive when the adapter supports
it. The signed Flatpak requests Bluetooth sockets and access to the BlueZ
service. The user still compares the verification code and accepts each transfer.

## Updating the signed Flatpak

Flatpak's in-app update portal cannot apply an update that adds permissions.
For the first update from 1.10.1 or earlier, use your system software manager
or quit Airdrop and run:

```sh
flatpak update io.github.fluffydisk.airdrop-linux//stable
```

This uses the existing signed repository and keeps the existing installation
and shared data. Later updates with the same permissions can use the in-app
update button.

Bluetooth support varies by adapter and phone. Apple AirDrop is unavailable.
