# Airdrop 1.6.8

Receive photos and files from a guest using a dedicated QR code on the Transfer
screen. Guests can upload without pairing to the workspace. Optionally select
specific files for them to download using Share selected files by QR.

Guest sessions have separate backend authorization, expire after ten minutes,
and can be stopped immediately. Guests cannot browse workspace folders, read
other files or the clipboard, or use trash and file-management APIs. Uploads go
to a fresh Guest uploads folder without replacing existing files. Limits are
100 MiB per file, 100 attempts, two concurrent uploads and 1 GiB per session.

The existing connection must be ready before creating a guest QR. Physical
Safari/iPhone validation remains pending; browser acceptance covers Chromium
with iPhone and Android profiles.
