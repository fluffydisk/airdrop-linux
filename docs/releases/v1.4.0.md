## Files, clipboard and simpler installation

- Upload selected or dropped files immediately, with a remembered ZIP option and retries for failed files only.
- Manage folders inside the shared Airdrop root: grid/list views, format icons, navigation, multi-selection, copy to a new folder, downloads and recoverable deletion.
- Paste clipboard images as PNG and text as UTF-8 files with Ctrl+V. Text fields keep their normal paste behavior.
- Check stable releases from Settings. Installed copies can update the desktop, server and web UI together, with checksum verification and rollback.

## Download options

**Full setup without compiling:** download `install-prebuilt.sh` and run it as your normal user. It selects your architecture, verifies the release bundle and runs the usual backend/system setup with the prebuilt application. No checkout or local Electron build is needed. System dependencies, sudo and Tailscale login may still be required.

```bash
curl -fL https://github.com/fluffydisk/airdrop-linux/releases/download/v1.4.0/install-prebuilt.sh -o install-prebuilt.sh
bash install-prebuilt.sh --version 1.4.0
```

**One executable file:** choose `Airdrop-1.4.0-x86_64.AppImage` (Intel/AMD 64-bit) or `Airdrop-1.4.0-aarch64.AppImage` (ARM64), enable execution and launch it. The AppImage contains the desktop companion; set up the local server, dufs and Tailscale separately. Its Settings opens replacement AppImage downloads; backend updates are separate. On systems restricting Electron's sandbox at temporary AppImage paths, use the prebuilt installer with its executable-specific AppArmor profile.

`SHA256SUMS` covers the public release assets. The `.zip` payloads and `airdrop-update.json` are used by the installed updater. The `.tar.gz` bundles are used by the stand-alone download script.

## Existing installations

Quit Airdrop before upgrading. Keep the same `AIRDROP_HOME` if you configured a custom root. Shared files, credentials, subscriptions and preferences are retained. Older versions without the update button need this one installer-based upgrade first.

See the [distribution guide](https://github.com/fluffydisk/airdrop-linux/blob/v1.4.0/docs/distribution.md) for installation details, build instructions and the AUR / Debian / RPM / Flathub roadmap. No package-manager submissions are included in this release.
